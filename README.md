# IGO Clothing Brand — storefront

متجر عربي بسيط باتجاه RTL، مصمم للهاتف أولًا. يعرض أمثلة منتجات، ويحوّل طلب كل قطعة إلى رسالة واتساب على الرقم الذي حدده صاحب المتجر. الصفحات ثابتة بلا اشتراك أو خدمة مدفوعة.

## المحتويات

- `index.html` — واجهة المتجر.
- `admin.html` — نموذج محلي لإضافة المنتجات وتعديلها وحذفها.
- `data/products.json` — بيانات المنتجات والأسعار التجريبية.
- `assets/` — الشعار المرفق و3 صور توضيحية مؤقتة.

كل أسماء المنتجات والأسعار والصور الحالية أمثلة وليست مخزونًا أو أسعارًا مؤكدة. استبدلها بالمنتجات الفعلية قبل الاعتماد على المتجر في البيع.

## لوحة الإدارة: حدود مهمة

لوحة `admin.html` ليست محمية بكلمة مرور أو تسجيل دخول. حفظها يتم في `localStorage` لهذا المتصفح والجهاز فقط، ولا يغيّر نسخة الموقع المنشورة ولا يشارك التعديلات مع الزوار. هذا متعمد لتجنب وضع سر أو رمز GitHub داخل موقع عام.

للنشر اليدوي: عدّل المنتجات من الصفحة، نزّل `products.json`، ثم استبدل `data/products.json` في المستودع على GitHub وارفع التغيير. لتحميل صورة جديدة، أضف ملف الصورة إلى `assets/` وارفعه، ثم اكتب مساره في لوحة الإدارة قبل تصدير JSON. صفحة المتجر تقرأ JSON المنشور بعد تحديث GitHub Pages.

## المعاينة المحلية

من هذا المجلد شغّل:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`. استخدام خادم محلي ضروري لتحميل ملف JSON؛ فتح `index.html` مباشرة عبر `file://` قد يمنع ذلك.

## نشر مجاني على GitHub Pages

بعد إنشاء مستودع عام باسم `igo-clothing-store` ورفع محتويات هذا المجلد إلى الفرع `main`، فعّل GitHub Pages من إعدادات المستودع باختيار **Deploy from a branch** ثم الفرع `main` والمجلد `/(root)`. رابط الموقع عادة يكون `https://<اسم-المستخدم>.github.io/igo-clothing-store/` بعد اكتمال النشر.

هذا موقع ثابت: الطلبات تُفتح كمحادثة واتساب فقط؛ لا توجد سلة أو بوابة دفع أو قاعدة بيانات/مخزون. كذلك لا توجد حماية إدارية أو حفظ مشترك. GitHub Pages مجاني للمستودعات العامة.

## صور المثال

صور الملابس مؤقتة للتصميم وليست صور منتجات IGO الفعلية. لا تستخدمها كتمثيل مضمون للمخزون؛ استبدلها بصور منتجاتك التي تملك حق استخدامها.
